## Full description
Tap once and the arrow flies. But what if there is a mirror in the way?

Ricochet Out is a puzzle about clearing every arrow off the board. Each arrow flies the way it points, and when it meets a mirror (/ or \) it turns 90 degrees and keeps going. If another arrow or a wall blocks it, it bounces back and you lose a heart. Work out which arrow goes first, and where each mirror will send it.

Features
- Mirrors: not just straight lines. Read the bending path to solve it.
- Every level is built to be solvable. Only the order matters.
- A hard level every 10, a super hard level every 25. Walls from level 25.
- Earn three stars by clearing without a mistake.
- Hints show an arrow that can leave now and its path; the hammer removes one arrow.
- Light up a constellation every 30 levels, from Orion to Draco.
- A new daily puzzle every day, with a streak bonus.
- Six skins to unlock with stardust.
- Colour-blind mode marks each arrow with a shape.
- Plays fully offline. No account, no login.
- No ads, no in-app purchases, no data collected.
